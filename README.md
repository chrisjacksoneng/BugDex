# BugDex MVP

A mobile-friendly bug collecting and identification app - "Pokemon GO for bugs!"

## Features

- **Profile Setup**: Create your bug collector profile with username, name, email, bio, and profile picture
- **Camera Capture**: Take or upload photos of bugs you find
- **Bug Collection**: Build your personal bug collection with details
- **Social Feed**: See what bugs other collectors have found
- **Bug Details**: View information about each bug including traits and descriptions

## Tech Stack

- Pure HTML, CSS, and JavaScript
- Mobile-responsive design
